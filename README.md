# Two Lines, Three Stories: Linear Equations Made Easy

An interactive Class 10 Mathematics web application that teaches **Pair of Linear Equations in Two Variables** (Intersecting, Parallel, Coincident, Consistent, and Inconsistent systems) visually.

## Folder Structure

```text
linear-equations-website/
├── index.html   # Main webpage structure and sections
├── style.css    # Responsive layout, cards, and UI styling
├── script.js    # Interactive HTML5 Canvas graph, ratio logic, and quiz
└── README.md    # Project overview and GitHub Pages guide
```

## How to Host on GitHub Pages

1. Extract this ZIP folder.
2. Create a new public repository on GitHub.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` into the root of the repository.
4. Go to **Settings → Pages**, select the `main` branch and `/ (root)` folder, and click **Save**.
